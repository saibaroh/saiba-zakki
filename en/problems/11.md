Black to move. You control the board, but White’s rook has strong sideways reach.

Is there a forced mate against White’s king in this position?

Squares are written file first, then rank, as labeled on the board (62 = file 6, rank 2).

<!-- answer -->

## Answer and explanation

**Yes, there is a mate (mate in 17).**

**☗B-53+ → ☖K-61 → ☗G*71 → ☖K-51 → ☗S*62 → ☖K-41 → ☗S*32 → ☖Gx32 → ☗Px32+ → ☖Kx32 → ☗+B-54 → ☖P-43 → ☗+Bx43 → ☖K-22 → ☗G*23 → ☖K-31 → ☗G-32**

```board

moves: 6d5c+ 5b6a G*7a 6a5a S*6b 5a4a S*3b 2b3b 3c3b+ 4a3b 5c5d 4b4c 5d4c 3b2b G*2c 2b3a 2c3b
caption: Answer
```

The key is the fifth move, ☗S*62.

This silver drop blocks the rook’s sideways reach, so you can drive the king toward the right side of the board.

If White takes with ☖Rx62, then after ☗+Bx62 → ☖Kx62 → ☗R*61, the rook drop is check. ☖K-52 is met by ☗S*53, mate.
