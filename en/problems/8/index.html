Problem 8

[3 dan and above · Next move] An ordinary-looking rook pawn exchange — is there a move here?

A next-move problem built from a game on Shogi Wars.

Black to move. White has just exchanged pawns on the rook file.

At first glance this looks like an ordinary position, but is there a strong move here?

Squares are written file first, then rank, as labeled on the board (85 = file 8, rank 5).

Show answer

Answer and explanation

☗B*85

It’s an unexpected bishop drop, but it has two aims:

  • ☗Bx63+, making a dragon horse while giving check
  • ☗P*87, trapping White’s rook

Both are troublesome for White.

White’s camp is weak against a rook, so if you can win the rook, you can drive White into a corner one-sidedly.

Other moves: ☗G-87 or ☗S-87

Defending with ☗G-87 or ☗S-87 is the calm approach, and that line isn’t bad either.

However, the correct move swings the game decisively in your favor, so it is the better choice.
