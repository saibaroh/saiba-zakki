将棋ウォーズの実戦から作った、即詰みがあるかどうかを判断する問題です。

```board
sfen: ln6l/r3kp1g1/p1p3P2/3B1+P1P1/1p4ppp/2P5P/PP1S+nb3/7R1/LN2KG1NL b G2Sgs4p 1
caption: 問題図（先手番）
hands: show
```

先手番です。盤面は制圧していますが、相手の飛車の横利きが強い局面です。

この局面で、後手玉に即詰みはあるでしょうか？

<!-- answer -->

## 解答・解説

**詰みあり（17手詰）**

**☗５三角成 → ☖６一玉 → ☗７一金 → ☖５一玉 → ☗６二銀 → ☖４一玉 → ☗３二銀 → ☖同金 → ☗同歩成 → ☖同玉 → ☗５四馬 → ☖４三歩 → ☗同馬 → ☖２二玉 → ☗２三金 → ☖３一玉 → ☗３二金**

```board
sfen: ln6l/r3kp1g1/p1p3P2/3B1+P1P1/1p4ppp/2P5P/PP1S+nb3/7R1/LN2KG1NL b G2Sgs4p 1
moves: 6d5c+ 5b6a G*7a 6a5a S*6b 5a4a S*3b 2b3b 3c3b+ 4a3b 5c5d 4b4c 5d4c 3b2b G*2c 2b3a 2c3b
caption: 解答手順
```

ポイントは、5手目の☗６二銀です。

この銀打ちで飛車の横利きが止まり、右辺に玉を追い込むことができます。

ここで☖同飛と取ると、☗同馬 → ☖同玉 → ☗６一飛 と、飛車打ちが王手になります。☖５二玉に☗５三銀で詰みです。

```board
sfen: ln6l/r3kp1g1/p1p3P2/3B1+P1P1/1p4ppp/2P5P/PP1S+nb3/7R1/LN2KG1NL b G2Sgs4p 1
```
