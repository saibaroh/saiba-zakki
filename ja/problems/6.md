最近実装された将棋ウォーズの新モード、詰めバトを早速遊んでいます！

私は詰将棋は大事だと思っていながらも、淡々としており対戦に比べると地道な訓練という感じだったので、楽しみながら詰将棋ができるのはありがたいです。

アクティブユーザーの多い「将棋ウォーズ」で色々な将棋の新しい対戦の試みを提供してもらえるのはありがたいですね。（スプリントモードもしかり）

イチ将棋ファンとして、どんなルールであれ、将棋に触れるのが楽しいと思う方が増えればいいなと思っています。

* * *

さて、このモードの問題は、大半は級位者向けの基礎的なレベルのものかな、と思っていますが実戦でどうしてもわからなかった問題がありました。

ぱっと見金を寄せていけば何とかなりそうながら工夫の手が必要。

それかあ…と思わず唸らされるような気づきにくい手でした。

```board

hands: show
caption: 問題図（先手番）
```

## 解答・解説

正解は６二金、８一玉に**８八香打**！がこの一手でした。

同馬や合駒で龍の縦利きが消えれば平凡に金寄りで詰み。
８三銀合は８二歩以下詰み。（有名な大道詰将棋のような受けですがここは簡単）
同龍は、同飛以下詰み。

### ８三銀合の手順

元記事の解答画面にある手順です。

**☗６二金 → ☖８一玉 → ☗８八香打 → ☖８三銀打 → ☗８二歩打 → ☖９二玉 → ☗８三金**まで、詰みです。

```board
sfen: l1k5+N/4s4/p1G1G4/2p1p1p2/3p2s1p/2P4+B1/P4PPKP/4R3L/L+r+b1G1GNs b 2NL2Ps5p 1
moves: 5c6b 7a8a L*8h S*8c P*8b 8a9b 7c8c
caption: ８三銀合の変化・7手
```

持ち駒の桂馬は要らなくて、５八飛を詰みに使うのが盲点で見えにくい手順でした。
