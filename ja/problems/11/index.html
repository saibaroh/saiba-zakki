第11問

【難問・詰む？詰まない？】飛車の横利きをかいくぐれるか

先手番です。盤面は制圧していますが、相手の飛車の横利きが強い局面です。

この局面で、後手玉に即詰みはあるでしょうか？

解答を見る

解答・解説

詰みあり（17手詰）

☗５三角成 → ☖６一玉 → ☗７一金 → ☖５一玉 → ☗６二銀 → ☖４一玉 → ☗３二銀 → ☖同金 → ☗同歩成 → ☖同玉 → ☗５四馬 → ☖４三歩 → ☗同馬 → ☖２二玉 → ☗２三金 → ☖３一玉 → ☗３二金

ポイントは、5手目の☗６二銀です。

この銀打ちで飛車の横利きが止まり、右辺に玉を追い込むことができます。

ここで☖同飛と取ると、☗同馬 → ☖同玉 → ☗６一飛 と、飛車打ちが王手になります。☖５二玉に☗５三銀で詰みです。
