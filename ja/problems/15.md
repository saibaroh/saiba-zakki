王手の受け方は、☗３六玉と☗５四玉のどちらかしかありません。どちらを選ぶべきでしょう？

## 解答・解説

**☗３六玉**

```board
sfen: ln+Pg3nl/ks3+RR2/pp1+PPp1pp/2p3P2/4sKB2/4+b4/PP3+n1PP/9/L6NL b 3GS4Ps 1
moves: 4e3f
caption: 解答図
```

### ☗５四玉は詰み

☗５四玉は、次のような展開で詰みます。

**☗５四玉 → ☖４五銀 → ☗４三玉 → ☖６五馬 → ☗５四金 → ☖同馬**

```board
sfen: ln+Pg3nl/ks3+RR2/pp1+PPp1pp/2p3P2/4sKB2/4+b4/PP3+n1PP/9/L6NL b 3GS4Ps 1
moves: 4e5d S*4e 5d4c 5f6e G*5d 6e5d
caption: ☖同馬まで（詰み）
```

一見すると、上に行けば味方の駒が多いので安全そうです。しかし、相手陣の駒の利きや、自分の駒が邪魔で、絶妙に詰みになります。

印象で動くと間違えやすそうな局面です。やはり、詰む詰まないは慎重に読まなければなりませんね。

### ☗３六玉のあとは逃れている

正解の☗３六玉以降は、次のような迫り方が一例です。

**☗３六玉 → ☖４六馬 → ☗同角 → ☖同成桂 → ☗２六玉 → ☖４八角 → ☗３七銀 → ☖同角成 → ☗同桂**

```board
sfen: ln+Pg3nl/ks3+RR2/pp1+PPp1pp/2p3P2/4sKB2/4+b4/PP3+n1PP/9/L6NL b 3GS4Ps 1
moves: 4e3f 5f4f 3e4f 4g4f 3f2f B*4h S*3g 4h3g+ 2i3g
caption: ☗同桂まで
```

相手の駒が少し足らず、逃れています。

一見どちらでも詰まなそうなときほど、危険です。
